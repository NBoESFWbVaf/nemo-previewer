# nemo-previewer
A Python extension for the “Nemo” file browser that provides true file previews, just like in Windows Explorer. 

## Warning
> *This extension is still under active development and may contain bugs. Use at your own risk.*

# What I Expect from a File Browser

First and foremost, I want a file browser that offers a modern look and feel. It shouldn’t be too cluttered, but it shouldn’t just display files—it should provide features exactly where I, as a user, need them, to be helpful. That means, for example, if I click on a font and it’s displayed in the preview, I should be able to install it right there—not through separate menus. Or an Office document that can be converted to a PDF right away with the click of a button.
